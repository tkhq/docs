Fee sponsorship and fixed rate are requested per quote, with `ACTIVITY_TYPE_CREATE_SWAP_QUOTE_V3`. The quote binds the features, so execution is unchanged: pass the quote to [`ACTIVITY_TYPE_EXECUTE_SWAP_V3`](/features/transaction-management/swap/execute-swap) as usual.

**Prerequisites:** the feature is [turned on with a spending window](/features/transaction-management/swap/early-access/enable-fee-sponsorship-and-fixed-rate) for your parent organization.

## Request a quote

`ACTIVITY_TYPE_CREATE_SWAP_QUOTE_V3` uses the same route and parameters as [`ACTIVITY_TYPE_CREATE_SWAP_QUOTE_V2`](/features/transaction-management/swap/get-swap-quote), plus two flags:

<ParamField body="parameters.feeSponsorship" type="boolean">
  Optional, defaults to `false`. When `true`, your organization pays the provider's fees for this swap.
</ParamField>

<ParamField body="parameters.fixedRate" type="boolean">
  Optional, defaults to `false`. When `true`, the wallet receives the quoted output at a fixed rate. Both `inputToken` and `outputToken` must be stablecoins supported for fixed rate. Same-chain and cross-chain routes both work.
</ParamField>

The flags are independent; set either or both.

```bash title="cURL"
curl --request POST \
  --url https://api.turnkey.com/public/v1/submit/create_swap_quote \
  --header 'Accept: application/json' \
  --header 'Content-Type: application/json' \
  --header "X-Stamp: <string> (see Stamps)" \
  --data '{
    "type": "ACTIVITY_TYPE_CREATE_SWAP_QUOTE_V3",
    "timestampMs": "<string> (e.g. 1745474677453)",
    "organizationId": "<ORGANIZATION_ID>",
    "parameters": {
      "signWith": "<WALLET_ACCOUNT_ADDRESS>",
      "inputToken": "eip155:8453/erc20:0x833589fCD6eDb6E08f4c7C32D4f71b54bdA02913",
      "outputToken": "eip155:42161/erc20:0xaf88d065e77c8cC2239327C5EDb3A432268e5831",
      "inputAmount": "1000000",
      "feeSponsorship": true,
      "fixedRate": true
    }
  }'
```

With the Go SDK, use `Client.CreateSwapQuoteV3`. The TypeScript SDK's `createSwapQuote` sends V2; until it adds V3, submit the activity with a stamped request as above.

The result is in `activity.result.createSwapQuoteResultV2.quotes`. Each quote has the V2 fields plus:

- `feeSponsorship`, `fixedRate`: the features this quote applies.
- `estimatedFixedRateAdjustmentUsd`: fixed-rate quotes only. The estimated USD cost of the fixed rate: positive is billed to you, negative is an earning credited against your transaction management charges at the end of the billing period. It is informational; the final amount is settled after the swap completes.

With fee sponsorship, `outputAmount` and `minOutputAmount` are no longer reduced by the provider's fees. Your client fee, if configured, still applies and is reflected in both.

## Execute the quote

Submit `ACTIVITY_TYPE_EXECUTE_SWAP_V3` with the quote's `quoteId`, amounts, and `minOutputAmount`, exactly as for a V2 quote. See [Execute a Swap](/features/transaction-management/swap/execute-swap).

Fee sponsorship and gas sponsorship are separate. Fee sponsorship covers the provider's fees and is set on the quote. Gas sponsorship covers the origin-chain transaction's gas and is set with `sponsor: true` on execute.

## Errors

A quote that can't apply a requested feature fails rather than falling back to an unsponsored or market-rate quote:

| Error code | Meaning |
| :-- | :-- |
| `SWAP_FEATURE_NOT_ENABLED` | The parent organization hasn't turned this feature on. |
| `SWAP_FIXED_RATE_PAIR_NOT_ELIGIBLE` | The token pair isn't eligible for a fixed rate. |
| `SWAP_FIXED_RATE_UNAVAILABLE` | The provider can't offer a fixed rate for this swap right now. |
| `SWAP_FEE_SPONSORSHIP_UNAVAILABLE` | The provider can't sponsor fees for this swap right now. |

A quote is also rejected when the feature's spending window is disabled, or when the swap's estimated cost would exceed the window's remaining capacity. Check [usage](/features/transaction-management/swap/early-access/enable-fee-sponsorship-and-fixed-rate#check-usage) or raise the limit.
