Sending transactions onchain has traditionally been painful: wallets need native gas tokens before they can do anything, and network congestion and fee spikes leave transactions stuck or dropped. Turnkey's transaction management handles this for wallets you manage with Turnkey, from a few API calls and without running your own RPC providers.

## What's included

- [**Broadcasting**](/features/transaction-management/broadcasting): send EVM and Solana transactions with one call. Turnkey constructs, signs, broadcasts, and tracks them, and can [sponsor the gas](/features/transaction-management/broadcasting/gas-sponsorship).
- [**Balances**](/features/transaction-management/balances): query token balances for wallet accounts and get balance change webhooks.
- [**Transaction history**](/features/transaction-management/transaction-history): query paginated EVM and Solana transaction history for wallet accounts.
- [**Funding**](/features/transaction-management/funding): let users on-ramp and off-ramp funds into their Turnkey wallets.
- [**Earn**](/features/transaction-management/earn): deposit into DeFi yield vaults from Turnkey wallets, with onchain fee collection for your organization.
- [**Swaps**](/features/transaction-management/swap): swap tokens through DEX aggregators, with your own fee.
