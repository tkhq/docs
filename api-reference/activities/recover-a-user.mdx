---
title: "Recover a user (deprecated)"
description: "Migration guidance for this deprecated authentication flow."
---

<Warning>
  This authentication flow is deprecated. Do not use it for new integrations.
</Warning>

Use encrypted OTP authentication, a recovery session with appropriate restrictions and MFA, and replacement authenticator enrollment with `CREATE_AUTHENTICATORS_V2`.

Follow the [replacement flow and migration guidance](/features/authentication/otp-migration-guide#replace-email-recovery) before updating your integration. The migration covers client-side encryption, client signing, and policy updates; plan them as one change.
