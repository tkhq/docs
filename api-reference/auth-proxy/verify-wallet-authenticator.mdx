<H3Bordered text="Authorizations" />

<ParamField header="X-Auth-Proxy-Config-Id" type="string" required={true}>
  Your Auth Proxy config ID, found in **Dashboard → AUTH**. See [Auth Proxy reference](/reference/auth-proxy) for setup.
</ParamField>

<H3Bordered text="Body" />

<ParamField body="message" type="string" required={true}>

SIWE or SIWS message. Ump accepts only the Turnkey supported login template.
</ParamField>

<ParamField body="signature" type="string" required={true}>

Wallet signature over the message. Ethereum: 65-byte hex personal_sign (r || s || v). Solana: 64-byte hex ed25519 signature.
</ParamField>

<ParamField body="publicKey" type="string" required={true}>

Wallet public key that signed the message. Ethereum: sec1 secp256k1 hex, compressed or uncompressed. Solana: 32-byte ed25519 hex.
</ParamField>


<H3Bordered text="Response" />
A successful response returns the following fields:

<ResponseField name="verificationToken" type="string" required={true}>Enclave-signed JWT binding the wallet, the wallet public key, and the ephemeral P-256 session key.</ResponseField>

<RequestExample>

```bash title="cURL"
curl --request POST \
  --url https://authproxy.turnkey.com/v1/verify_wallet_authenticator \
  --header 'Accept: application/json' \
  --header 'Content-Type: application/json' \
  --header "X-Auth-Proxy-Config-Id: <string> (see Authorizations)" \
  --data '{
    "message": "<string>",
    "signature": "<string>",
    "publicKey": "<string>"
}'
```

</RequestExample>

<ResponseExample>

```json 200
{
  "verificationToken": "<string>"
}
```

</ResponseExample>
