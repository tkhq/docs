<H3Bordered text="Authorizations" />

<ParamField header="X-Auth-Proxy-Config-Id" type="string" required={true}>
  Your Auth Proxy config ID, found in **Dashboard → AUTH**. See [Auth Proxy reference](/reference/auth-proxy) for setup.
</ParamField>


<H3Bordered text="Response" />
A successful response returns the following fields:

<ResponseField name="turnstileSiteKey" type="string" required={false}>Site key for Turnstile, used to protect WalletKit flows with bot detection.</ResponseField>

<RequestExample>

```bash title="cURL"
curl --request POST \
  --url https://authproxy.turnkey.com/v1/wallet_kit_client_params \
  --header 'Accept: application/json' \
  --header 'Content-Type: application/json' \
  --header "X-Auth-Proxy-Config-Id: <string> (see Authorizations)" \
  --data '{}'
```

</RequestExample>

<ResponseExample>

```json 200
{
  "turnstileSiteKey": "<string>"
}
```

</ResponseExample>
