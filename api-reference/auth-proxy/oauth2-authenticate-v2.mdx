---
title: "OAuth 2.0 Authenticate V2"
description: "Submit encrypted OAuth 2.0 inputs through Auth Proxy and receive a Turnkey OIDC token."
---

`POST https://authproxy.turnkey.com/v1/oauth2_authenticate_v2`

## Authorization

Send `X-Auth-Proxy-Config-Id: <your Auth Proxy config ID>` and `Content-Type: application/json`. OAuth must be allowed in that proxy configuration. Follow the [Auth Proxy origin requirements](/features/authentication/auth-proxy).

## Request body

```json
{
  "oauth2CredentialId": "<credential UUID returned by initialization>",
  "encryptedMessage": "<serialized encrypted message returned by the helper>",
  "targetPublicKey": "<matching target public key returned by the helper>"
}
```

All three fields are required. First [initialize](/api-reference/auth-proxy/init-oauth2-authenticate-v2), verify the target, and encrypt on the client. Encode `encryptedMessage` as a string, not a nested object. Don't include the legacy `authCode`, `codeVerifier`, or `nonce` fields; they travel inside `encryptedMessage`.

## Response

```json
{
  "oidcToken": "<Turnkey OIDC token>"
}
```

Continue [OAuth Login](/api-reference/auth-proxy/oauth-login) or signup with the same client session key you used to compute the nonce. See [Auth Proxy auth flows](/features/authentication/auth-proxy#auth-flows) for the full sequence and the [encrypted payload](/api-reference/activities/oauth-20-authentication-v2#encrypted-payload) for the fields to encrypt.
