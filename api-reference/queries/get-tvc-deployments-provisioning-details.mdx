---
title: "Get TVC deployment's provisioning details"
description: "Get the attestation document and manifest envelope of the provisioning enclave for a TVC deployment."
---

import { Authorizations } from "/snippets/api/authorizations.mdx";
import { H3Bordered } from "/snippets/h3-bordered.mdx";
import { NestedParam } from "/snippets/nested-param.mdx";
import { EndpointPath } from "/snippets/api/endpoint.mdx";

<EndpointPath type="query" path="get_tvc_deployment_provisioning_details" />

<Authorizations />

<H3Bordered text="Body" />

<ParamField body="organizationId" type="string" required={true}>

Unique identifier for a given Organization.
</ParamField>

<ParamField body="deploymentId" type="string" required={true}>

Unique identifier for a given TVC Deployment.
</ParamField>


<H3Bordered text="Response" />
A successful response returns the following fields:

<ResponseField name="attestationDocument" type="string" required={false}>The attestation document of the provisioning enclave. Present only when a deployment is awaiting provisioning.</ResponseField>
<ResponseField name="manifestEnvelope" type="string" required={false}>The manifest envelope containing the TVC deployment's manifest and signatures. Present only when a deployment is awaiting provisioning.</ResponseField>
<ResponseField name="provisioningState" type="enum" required={true}>
provisioningState field

Enum options: `PROVISIONING_STATE_PENDING`, `PROVISIONING_STATE_AWAITING_PROVISION`, `PROVISIONING_STATE_PROVISIONED`

</ResponseField>

```bash title="cURL"

  --header "X-Stamp: <string> (see Authorizations)" \
  --data '{

```
