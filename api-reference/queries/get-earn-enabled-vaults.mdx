---
title: "Get Earn enabled vaults"
description: "Get the organization's deployed wrappers with on-chain total deposited and live APY. The management view, distinct from per-wallet positions."
---

<EndpointPath type="query" path="list_earn_enabled_vaults" />

<Authorizations />

<H3Bordered text="Body" />

<ParamField body="organizationId" type="string" required={true}>

Unique identifier for a given Organization.
</ParamField>

<ParamField body="provider" type="enum<string>" required={false}>

Enum options: `EARN_PROVIDER_MORPHO`, `EARN_PROVIDER_AAVE`
</ParamField>

<ParamField body="caip19" type="string" required={false}>

Optional filter: only return enabled vaults whose underlying asset matches this CAIP-19 asset ID (e.g. 'eip155:8453/erc20:0x833589...'). The chain is taken from the CAIP-19 identifier.
</ParamField>

<ParamField body="includeExposure" type="boolean" required={false}>

When true, populate each vault's exposures (the underlying markets it allocates into). This costs an extra provider query per vault, so leave it off for list views.
</ParamField>


<H3Bordered text="Response" />
A successful response returns the following fields:

<ResponseField name="enabledVaults" type="array" required={false}>
  The organization's deployed wrappers.
  <Expandable title="enabledVaults details">
    <NestedParam parentKey="enabledVaults" childKey="vaultAddress" type="string" required={false}>
Address of the underlying yield vault.
</NestedParam>
<NestedParam parentKey="enabledVaults" childKey="wrapperAddress" type="string" required={false}>
Address of the deployed fee wrapper (the deposit target).
</NestedParam>
<NestedParam parentKey="enabledVaults" childKey="provider" type="enum" required={false}>
provider field
  
Enum options: `EARN_PROVIDER_MORPHO`, `EARN_PROVIDER_AAVE`

</NestedParam>
<NestedParam parentKey="enabledVaults" childKey="caip19" type="string" required={false}>
CAIP-19 asset ID of the vault's underlying asset (e.g. 'eip155:8453/erc20:0x833589...'); the chain is encoded in the identifier.
</NestedParam>
<NestedParam parentKey="enabledVaults" childKey="apyPct" type="string" required={false}>
Gross annual percentage yield, expressed as a decimal fraction (before fees).
</NestedParam>
<NestedParam parentKey="enabledVaults" childKey="totalDeposited" type="string" required={false}>
Total deposited through this wrapper (wrapper TVL), in raw on-chain units of the underlying asset.
</NestedParam>
<NestedParam parentKey="enabledVaults" childKey="display" type="object" required={false}>
      display field
      <Expandable title="display details">
        <NestedParam parentKey="enabledVaults.display" childKey="usd" type="string" required={false}>
USD value, for display only.
</NestedParam>
<NestedParam parentKey="enabledVaults.display" childKey="crypto" type="string" required={false}>
Normalized amount in the asset's own units, for display only.
</NestedParam>

      </Expandable>
    </NestedParam>
<NestedParam parentKey="enabledVaults" childKey="netApyPct" type="string" required={false}>
Annual percentage yield net of fees, expressed as a decimal fraction.
</NestedParam>
<NestedParam parentKey="enabledVaults" childKey="clientFeeBps" type="string" required={false}>
Client fee taken on yield, in basis points.
</NestedParam>
<NestedParam parentKey="enabledVaults" childKey="depositsDisabled" type="boolean" required={false}>
When true, deposits to this wrapper are rejected; withdrawals are unaffected. Toggled via EarnSetWrapperState.
</NestedParam>
<NestedParam parentKey="enabledVaults" childKey="name" type="string" required={false}>
Human-readable vault name from the provider (e.g. 'Steakhouse Prime USDC' for Morpho; the reserve symbol for Aave).
</NestedParam>
<NestedParam parentKey="enabledVaults" childKey="curator" type="string" required={false}>
Vault curator name(s), comma-separated when a vault has multiple. Empty for providers without curators (e.g. Aave).
</NestedParam>
<NestedParam parentKey="enabledVaults" childKey="claimableClientFee" type="string" required={false}>
The client's claimable fee (releasable now), in raw on-chain units of the underlying asset (the caip19 asset). Turnkey's fee is excluded. Only returned to the parent org; unset when a sub-org queries.
</NestedParam>
<NestedParam parentKey="enabledVaults" childKey="claimableClientFeeDisplay" type="object" required={false}>
      claimableClientFeeDisplay field
      <Expandable title="claimableClientFeeDisplay details">
        <NestedParam parentKey="enabledVaults.claimableClientFeeDisplay" childKey="usd" type="string" required={false}>
USD value, for display only.
</NestedParam>
<NestedParam parentKey="enabledVaults.claimableClientFeeDisplay" childKey="crypto" type="string" required={false}>
Normalized amount in the asset's own units, for display only.
</NestedParam>

      </Expandable>
    </NestedParam>
<NestedParam parentKey="enabledVaults" childKey="clientFeeWallet" type="string" required={false}>
The wallet address that receives the client's fee payouts on-chain. Unset when a sub-org queries.
</NestedParam>
<NestedParam parentKey="enabledVaults" childKey="liquidity" type="string" required={false}>
Assets currently withdrawable from the underlying vault without a reallocation, in raw on-chain units of the underlying asset. This is the vault's liquidity, not the wrapper's balance. Empty when the provider does not report it.
</NestedParam>
<NestedParam parentKey="enabledVaults" childKey="liquidityDisplay" type="object" required={false}>
      liquidityDisplay field
      <Expandable title="liquidityDisplay details">
        <NestedParam parentKey="enabledVaults.liquidityDisplay" childKey="usd" type="string" required={false}>
USD value, for display only.
</NestedParam>
<NestedParam parentKey="enabledVaults.liquidityDisplay" childKey="crypto" type="string" required={false}>
Normalized amount in the asset's own units, for display only.
</NestedParam>

      </Expandable>
    </NestedParam>
<NestedParam parentKey="enabledVaults" childKey="exposures" type="array" required={false}>
      The underlying markets the vault allocates into, ranked by supplied amount descending. Only populated when the request sets include_exposure, and only for providers that expose an allocation breakdown (Morpho).
      <Expandable title="exposures details">
        <NestedParam parentKey="enabledVaults.exposures" childKey="marketId" type="string" required={false}>
Provider-specific identifier for the market (the Morpho Blue market id).
</NestedParam>
<NestedParam parentKey="enabledVaults.exposures" childKey="collateralSymbol" type="string" required={false}>
Symbol of the market's collateral asset (e.g. 'cbBTC'). Empty for an idle/uncollateralized market.
</NestedParam>
<NestedParam parentKey="enabledVaults.exposures" childKey="collateralCaip19" type="string" required={false}>
CAIP-19 asset ID of the market's collateral asset. Empty for an idle/uncollateralized market.
</NestedParam>
<NestedParam parentKey="enabledVaults.exposures" childKey="lltvPct" type="string" required={false}>
The market's liquidation loan-to-value, expressed as a decimal fraction (e.g. '0.86' for 86%).
</NestedParam>
<NestedParam parentKey="enabledVaults.exposures" childKey="supplied" type="string" required={false}>
Assets the vault supplies to this market, in raw on-chain units of the underlying asset.
</NestedParam>
<NestedParam parentKey="enabledVaults.exposures" childKey="display" type="object" required={false}>
      display field
      <Expandable title="display details">
        <NestedParam parentKey="enabledVaults.exposures.display" childKey="usd" type="string" required={false}>
USD value, for display only.
</NestedParam>
<NestedParam parentKey="enabledVaults.exposures.display" childKey="crypto" type="string" required={false}>
Normalized amount in the asset's own units, for display only.
</NestedParam>

      </Expandable>
    </NestedParam>
<NestedParam parentKey="enabledVaults.exposures" childKey="sharePct" type="string" required={false}>
This market's share of the vault's supplied assets, as a decimal fraction (e.g. '0.997' for 99.7%).
</NestedParam>

      </Expandable>
    </NestedParam>

  </Expandable>
</ResponseField>
