---
title: "Get Earn vault catalog"
description: "Get the catalog of all wrappable yield vaults across supported chains, enriched with live TVL and APY. Annotates which vaults the organization has already enabled."
---

<EndpointPath type="query" path="list_earn_vaults" />

<Authorizations />

<H3Bordered text="Body" />

<ParamField body="organizationId" type="string" required={true}>

Unique identifier for a given Organization. Annotates which vaults the organization has already enabled.
</ParamField>

<ParamField body="provider" type="enum<string>" required={false}>

Enum options: `EARN_PROVIDER_MORPHO`, `EARN_PROVIDER_AAVE`
</ParamField>

<ParamField body="caip19" type="string" required={true}>

CAIP-19 asset ID (e.g. 'eip155:8453/erc20:0x833589...') to return vaults for. Only vaults whose underlying asset matches are returned; the chain is taken from the CAIP-19 identifier.
</ParamField>

<ParamField body="paginationOptions" type="object" required={false} path="paginationOptions">
  <p>paginationOptions field</p>
  <Expandable title="details">
    <NestedParam parentKey="paginationOptions" childKey="limit" type="string" required={false} default="">
    A limit of the number of object to be returned, between 1 and 100. Defaults to 10.
    </NestedParam>
    
    <NestedParam parentKey="paginationOptions" childKey="before" type="string" required={false} default="">
    A pagination cursor. This is an object ID that enables you to fetch all objects before this ID.
    </NestedParam>
    
    <NestedParam parentKey="paginationOptions" childKey="after" type="string" required={false} default="">
    A pagination cursor. This is an object ID that enables you to fetch all objects after this ID.
    </NestedParam>
  </Expandable>
</ParamField>

<H3Bordered text="Response" />
A successful response returns the following fields:

<ResponseField name="vaults" type="array" required={false}>
  The catalog of wrappable vaults, sorted by TVL (USD) descending. To page, pass page_info.end_cursor as the pagination after cursor.
  <Expandable title="vaults details">
    <NestedParam parentKey="vaults" childKey="vaultAddress" type="string" required={false}>
Address of the underlying yield vault.
</NestedParam>
<NestedParam parentKey="vaults" childKey="provider" type="enum" required={false}>
provider field
  
Enum options: `EARN_PROVIDER_MORPHO`, `EARN_PROVIDER_AAVE`

</NestedParam>
<NestedParam parentKey="vaults" childKey="caip19" type="string" required={false}>
CAIP-19 asset ID of the vault's underlying asset (e.g. 'eip155:8453/erc20:0x833589...'); the chain is encoded in the identifier.
</NestedParam>
<NestedParam parentKey="vaults" childKey="tvl" type="string" required={false}>
Total value locked in the vault, in raw on-chain units of the underlying asset. The catalog is sorted by the USD value of this.
</NestedParam>
<NestedParam parentKey="vaults" childKey="apyPct" type="string" required={false}>
Current annual percentage yield, expressed as a decimal fraction (e.g., '0.0812' for 8.12%).
</NestedParam>
<NestedParam parentKey="vaults" childKey="enabled" type="boolean" required={false}>
Whether the organization has enabled this vault.
</NestedParam>
<NestedParam parentKey="vaults" childKey="display" type="object" required={false}>
      display field
      <Expandable title="display details">
        <NestedParam parentKey="vaults.display" childKey="usd" type="string" required={false}>
USD value, for display only.
</NestedParam>
<NestedParam parentKey="vaults.display" childKey="crypto" type="string" required={false}>
Normalized amount in the asset's own units, for display only.
</NestedParam>

      </Expandable>
    </NestedParam>
<NestedParam parentKey="vaults" childKey="name" type="string" required={false}>
Human-readable vault name from the provider (e.g. 'Steakhouse Prime USDC' for Morpho; the reserve symbol for Aave).
</NestedParam>
<NestedParam parentKey="vaults" childKey="curator" type="string" required={false}>
Vault curator name(s), comma-separated when a vault has multiple. Empty for providers without curators (e.g. Aave).
</NestedParam>
<NestedParam parentKey="vaults" childKey="liquidity" type="string" required={false}>
Assets currently withdrawable from the vault without a reallocation, in raw on-chain units of the underlying asset. Empty when the provider does not report it.
</NestedParam>
<NestedParam parentKey="vaults" childKey="liquidityDisplay" type="object" required={false}>
      liquidityDisplay field
      <Expandable title="liquidityDisplay details">
        <NestedParam parentKey="vaults.liquidityDisplay" childKey="usd" type="string" required={false}>
USD value, for display only.
</NestedParam>
<NestedParam parentKey="vaults.liquidityDisplay" childKey="crypto" type="string" required={false}>
Normalized amount in the asset's own units, for display only.
</NestedParam>

      </Expandable>
    </NestedParam>

  </Expandable>
</ResponseField>
